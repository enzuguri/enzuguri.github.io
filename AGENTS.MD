# Repository Guide

## Purpose

This repository is a small Python static site generator for an Obsidian digital garden. Markdown notes are authored in the Obsidian vault under `content/` and rendered as static HTML into `dist/` for deployment to a static host.

The older GitHub Pages scaffold remains in the repository history and some legacy assets remain under `javascripts/` and `stylesheets/`. The active site is generated by `generator.py` and uses the Jinja templates under `templates/`.

## Development

Use `uv` for Python environments and dependencies:

```sh
uv sync
uv run garden
uv run garden dev
```

The normal build command is `uv run garden`. The development command starts a live-reloading server at `http://127.0.0.1:5500`.

Set `VAULT_DIR` when building a different Obsidian vault:

```sh
VAULT_DIR=/path/to/vault uv run garden
```

## Project Layout

- `generator.py`: discovers notes, filters unpublished frontmatter, resolves wikilinks, builds backlinks, renders templates, and copies attachments.
- `content/`: the current Obsidian vault and its Markdown notes.
- `templates/`: Jinja2 page templates.
- `stylesheets/styles.css`: source stylesheet copied to `dist/styles.css` during builds.
- `dist/`: generated output; it is ignored by Git.
- `pyproject.toml` and `uv.lock`: dependency and environment definitions. Keep them in sync when changing Python dependencies.

## Content Rules

- Notes use `.md` files and retain their relative directory paths in generated URLs.
- `published: false` in YAML frontmatter prevents a note from being rendered.
- Wikilinks use Obsidian syntax such as `[[Welcome]]` or `[[Welcome|Home]]`.
- Non-Markdown files in the vault are copied to the matching location in `dist/`; hidden Obsidian metadata directories are excluded.

## Agent Expectations

- Keep generated output out of commits; run the build to verify it instead.
- Prefer focused changes that preserve the existing CLI and vault layout.
- Run `uv run garden` and `uv run python -m compileall -q generator.py` after Python or template changes.
- Do not commit `.venv/`, `dist/`, Python caches, or `*.egg-info/` directories.
